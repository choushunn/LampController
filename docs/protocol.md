# 智能灯光控制器通信协议

本协议为文本命令协议。所有命令均为 ASCII 字符并以 `#` 结尾。通信参数：**波特率 19200，数据位 8，无校验，停止位 1**。

## 一、输出与亮度命令

| 命令 | 说明 |
|------|------|
| `SPA<数值>#` | 通道 1 输出与亮度，数值 0-255 |
| `SPB<数值>#` | 通道 2 输出与亮度，数值 0-255 |
| `SPC<数值>#` | 通道 3 输出与亮度，数值 0-255（依据 SPA/SPB 命名规律扩展，需真机验证） |
| `SPD<数值>#` | 通道 4 输出与亮度，数值 0-255（依据 SPA/SPB 命名规律扩展，需真机验证） |

## 二、参数命令

| 命令 | 说明 |
|------|------|
| `S_CTRL:1#` | 允许通道输出 |
| `S_MOD:0#` | 稳定数字调光 |
| `S_MOD:1#` | 频闪模式 |
| `S_PWMP:0#` | 47.5K 频率 |
| `S_PWMP:1#` | 95K 频率 |
| `S_ALL#` | 执行以上参数 |

## 三、状态查询命令

| 命令 | 说明 |
|------|------|
| `S_VER:#` | 固件版本 |
| `S_MOD:#` | 当前模式 |
| `S_PWMP:#` | 当前频率 |
| `S_CTRL:#` | 输出控制状态 |
| `S_TEMP:#` | 温度 |
| `S_VOLT:#` | 电压原始值 |
| `S_CRV:#` | 电流原始值 |
| `S_ERRS:#` | 保护错误码 |

## 四、命令序列

- **稳定模式初始化**：发送 `S_MOD:0#`、`S_PWMP:1#`、`S_CTRL:1#`，随后将四个通道输出置零并发送 `S_ALL#` 执行。
- **单通道设置**：如需恢复稳定模式，先发送 `S_MOD:0#`、`S_PWMP:1#`、`S_CTRL:1#`，再发送对应通道亮度命令，最后发送 `S_ALL#` 并视需要恢复稳定模式参数。
- **双通道以上设置**：按通道依次发送亮度命令，再发送 `S_ALL#` 执行。
- **应用设置**：发送 `S_ALL#` 执行当前参数，如需恢复稳定数字调光 95K，随后发送 `S_MOD:0#` 与 `S_PWMP:1#`。

## 五、响应格式

设备响应为包含关键字的文本。例如 `S_VER:#` 的响应中包含 `VER` 后跟数值，`S_VOLT:#` 的响应中包含 `VOLT` 后跟电压原始值，`S_CRV:#` 的响应中包含 `CRV` 或 `CUR` 后跟电流原始值。

解析程序在响应文本中忽略大小写查找关键字，跳过空白与冒号后读取带符号十进制整数。
